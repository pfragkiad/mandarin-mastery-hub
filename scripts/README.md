# Importers and font builders

Run scripts from the repository root. Importer-only pinned inputs belong in [importer/data/](../importer/data/README.md); runtime outputs belong in [public/data/](../public/data/README.md) or [src/data/](../src/data/README.md). Standalone analysis outputs belong in [reports/](../reports/README.md). Read [catalog.md](../public/data/catalog.md) before changing catalogue inputs or output schemas.

| Script | Usage and output |
| --- | --- |
| `import-etymology.py` | Run `python scripts/import-etymology.py --write` to generate complementary `public/data/etymology/index.json`, lazy glyph shards and `reports/etymology-association-audit.json`; `--check` verifies regeneration without writes. Uses verified source downloads and the shared Node bridge, with no network/database. Run `python scripts/import-etymology.test.py` for source-text, duplicate-ID, ambiguous-form, contextual and graphical-boundary checks. See [the frontend contract](../public/data/etymology/README.md). |
| `export-etymology-context.mjs` | Read-only bridge called by the etymology importer with a temporary output path. Uses shared library/radical/contextual adapters, direct-G selection and IDS parsing; exports exact identity snapshots and textual structural evidence, never geometry or replacement trees. |
| `shuowen-translation-batches.py` | `--prepare` extracts 99 exact, checksum-bound batches from the pinned Shuowen archive. Authors use `save_batch` to store complete English AI draft dictionaries; it does not call a translation service. The etymology importer requires all 9,833 source IDs and validates source-text hashes before attaching separate English fields. See [the translation guide](../importer/data/etymology/translations/README.md). |
| `export-shuowen-review.py` | Run `python scripts/export-shuowen-review.py` to write `reports/shuowen-english-review.txt`: all 9,833 source-bound drafts in numeric ID order, one entry per line with explicit field labels, wide visible separators, blank lines, uncertainty markers and source notices. Reads and validates the existing sources/drafts without modifying them. |
| `import-shuowen-review.py` | `reports/shuowen-review-handoff.zip --write` applies the supplied English/uncertainty corrections and preserves the ZIP/manifest under `importer/data/etymology/translations/review/`. `--check` validates current drafts against the corrected copy. Original Chinese stays unchanged; the etymology generator attaches the 28 alternative readings as explicit editorial apparatus. Run `python scripts/shuowen-review.test.py`. |
| ↳ uncertainty follow-up | `python scripts/import-shuowen-review.py --uncertain-followup reports/shuowen-still-uncertain-only.zip --write` applies the six English differences in the supplied 884-entry subset and preserves both review inputs. Included and omitted uncertainty flags remain unchanged. Later `--check` validates the combined working copy. |
| ↳ complete v2 working copy | `python scripts/import-shuowen-review.py --full-v2 reports/shuowen-english-uncertainty-reviewed-v2.txt --write` applies the full file's 11 further English edits and 15 explicit flag resolutions. Verifies all keys/Chinese readings and exact agreement with the 884-entry subset; preserves the input and its manifest. Later commands replay all saved review stages. |
| ↳ external v3 case review | `python scripts/import-shuowen-review.py --external-v3 reports/shuowen-884-external-verification-v3.zip --write` validates the 884-case register, 222 evidence records, full master, remaining subset and reported counts; applies 166 English edits and 109 flag clearances. Keeps unchecked cases unchanged and supplied case evidence separate from lexical pronunciation/geometry. |
| `download-etymology-sources.py` | Run `python scripts/download-etymology-sources.py --download` to stage pinned Howell text/PDF and Shuowen JSON source archive, license notices and `manifest.json` under `importer/data/etymology/`; `--check` audits source hashes, inventories and embedded metadata/notices offline. `--refresh-metadata` rebuilds root dataset metadata from verified originals, preserving acquisition dates and source revisions. | `import-lesson-core.py` | Historical v3.2 migration; requires its removed input from Git history. Cross-checks all templates and active lessons/curricula against the 19 supplied canonical Core v3.2.0 files, then copies exact source bytes with `--write`. Leaves local Python tools and legacy snapshots separate; `--report` records checksums. Requires jsonschema. |

Generation can overwrite its documented output files. Review the input version, intended output, and resulting diff. Preserve exact glyph identities, nulls, record IDs, source provenance, and checksum-bound bytes. Media exports contain CDN URLs and attribution; do not add audio binaries to the repository.

Validate changed outputs with the relevant data, pronunciation, geometry, and font-coverage tests. For the full app run `npm test` and `npx tsc --noEmit`; Windows PowerShell may require `npm.cmd` and `npx.cmd`. Importer output comparisons should use temporary output directories when checking a path-only change.

- `import-component-strokes.py` — fills `public/data/components.json` rows that record no stroke count with Unicode Unihan 17.0.0 `kTotalStrokes` (single-valued only); radical supplement symbols Unihan doesn't cover stay uncounted. Run before `import-radical-strokes.ts`, which uses these counts for family forms its source leaves at null.
