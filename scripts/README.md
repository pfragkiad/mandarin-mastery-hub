# Importers and font builders

Run scripts from the repository root. Importer-only pinned inputs belong in [importer/data/](../importer/data/README.md); runtime outputs belong in [public/data/](../public/data/README.md) or [src/data/](../src/data/README.md). Standalone analysis outputs belong in [reports/](../reports/README.md). Read [catalog.md](../public/data/catalog.md) before changing catalogue inputs or output schemas.

## Levels 1-5 official-numbering migration tools

- `reconcile-hsk-level1-5-numbering.py --write` / `--check` builds/checks five new versioned handoffs and audio manifests against the preserved official PDF and exact runtime binding ledger.
- `hsk_numbering.py` supplies the read-only legacy serial view for immutable lesson package validation; never write that compatibility view to vocabulary.
- Active `import-hsk-level1.mjs` through `import-hsk-level5.mjs` use source versions 1.7.2 / 1.1.2 / 1.1.3 / 1.1.2 / 1.0.6 and retain UUIDs, order and audio through explicit old/current checksum checks.
- `build-character-hsk-examples.py` selects exact currently imported handoffs, preventing historical duplicate versions from being mixed into the sidecar.

See the [migration report](../reports/hsk-level1-5-official-numbering-migration.md).

- `validate-hsk-level1-5-numbering.mjs` independently checks all current official tuples, runtime UUID/order/readings/audio against the frozen ledger, versioned manifest identities, compact sizes and repeat-import equality. Run `node scripts/validate-hsk-level1-5-numbering.mjs`.
