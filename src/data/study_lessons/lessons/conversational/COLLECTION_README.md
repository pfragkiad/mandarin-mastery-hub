# Conversational Mandarin — Independent Course

A complete course of 15 topic-based lessons covering greetings, introductions, language ability, asking for directions, invitations, shopping, scheduling, and other everyday situations. Each lesson provides a 4-turn model dialogue, two explained grammar patterns, a review set, four questions (including a complete model speaking response), and stable progress checkpoints.

## Contents

- `topics/`: 15 ZIPs, each with canonical JSON, regenerated HTML and Markdown, and `report.md`.
- `../curricula/CONVERSATIONAL_MANDARIN.json`: existing course structure, updated learner-facing titles.
- `TOPIC_LESSON_INDEX.json`: updated lesson index.
- `BROWSE_BY_TOPIC.html`: offline topic browser (local font fallbacks).
- `QUALITY_REPORT.json` and `EDITORIAL_AUDIT.md`: validation and release notes.

**Versions:** Core Project Sources v3.3.1; taxonomy v2.0.0; general lesson JSON schema v3.2.0.

The dialogues are independently authored educational examples. Any source-specific provenance remains in the corresponding report files.
