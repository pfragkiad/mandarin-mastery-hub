# Conversational Mandarin — topic lessons

Contains the 15 topic-organized conversational lessons only, plus the Conversational Mandarin curriculum, offline topic browser, validation/review reports, and source transcripts. No HSK or independent-character lessons are included.

Each topic-lesson ZIP contains its own JSON, HTML, Markdown and report.md.

The lesson JSON uses the existing v3.1.0 schema; no Core update is required.
