# HSK 3.0 Level 1 lessons

This bundle contains 21 topic lessons with 300 vocabulary entries and 600 word-card examples. The lessons use vocabulary release v1.7.1 and topic taxonomy v2.0.0. Lesson JSON retains schema v3.2.0.

The v1.7.1 update revises 33 card examples and synchronizes three related quiz prompts and answers across JSON, HTML and Markdown. Each lesson ZIP contains those three formats and a content report. Open the HTML file for the teaching view with Kai-style fonts. The vocabulary-card examples are stored in the lesson JSON.

The curriculum order and lesson IDs carry over from the source bundle. See `audits/source_example_discrepancies.json` for a previously corrected pinyin segmentation at entry 36.
