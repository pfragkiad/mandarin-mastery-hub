# Pinyin inventory and recordings

These generated sidecars support the Pinyin sounds pages (Sound chart, Tone pairs, Tone changes), exact-reading links, and pronunciation playback. `src/lib/pinyin-guide.ts` loads them through dynamic imports so the recording manifest stays out of initial page bundles.

| File | Shape and usage |
| --- | --- |
| `inventory.json` | `{ source, syllables }`: dictionary-attested syllable spellings and tones with source metadata. `loadSyllableInventory()` can load it alone for glyph-card Sound chart links. |
| `neutral-audio.json` | `{ source, recordings }`: neutral-tone sound id (`ba5`) to the exact single-character word recording heard for it (word, reading, HSK index, CDN URL, source, license, duration). Generated by `python3 scripts/import-neutral-pinyin-audio.py --write`; verify with `--check`. Merged by `loadPinyinData()`. |
| `tone-pairs.json` | `{ source, examples, … }`: the Tone pairs / Tone changes examples (exact Vocabulary entry ID, headword, source reading, dictionary tones, separate *expected in speech* draft, Sound chart links and the word card's own CDN recording with speaker, licence and SHA-256). Generated by `python3 scripts/import-tone-pairs.py --write` from [importer/data/tone-pairs](../../../importer/data/tone-pairs/README.md); verify with `--check` (add `--verify-cdn` to re-hash the recordings). Loaded by `loadTonePairs()` in `src/lib/tone-pairs.ts`. |
| `audio.json` | `{ source, recordings }`: recording ID to CDN URL and recorded attachment metadata. `loadPinyinData()` loads it together with the inventory and validates expected recording coverage. |

Generate both files with `python scripts/import-pinyin-audio.py <material-dir> <uploads-dir>` from the repository root. The importer verifies supplied recording bytes and checksums before accepting uploaded CDN references. External input paths remain command-line arguments; do not commit audio binaries here.

Keep exact syllable/tone bindings and all source, speaker, and license fields. audio-cmn's withdrawn neutral-tone recordings stay excluded; neutral tones play only from `neutral-audio.json`; no pronunciation is inferred or substituted. See [AGENTS.md](AGENTS.md) for the local rules and [the parent data guide](../README.md) for packaging conventions.

`loadTonePairs()` retains the generated authored sidecar unchanged and enriches its runtime view through [tone-pair-vocabulary.ts](../../lib/tone-pair-vocabulary.ts) with current exact two-character Vocabulary words carrying Yue Tan recordings. Recorded pinyin is split only through the shared attested syllable inventory; ambiguous readings, missing recordings, and unauthored 一/不 context are excluded. Additions preserve vocabulary IDs, readings, meanings and audio pointers; they do not claim upstream hashes absent from the vocabulary attachment. The 3+3 speech layer remains an explicitly unreviewed teaching draft. Word sound links and the tone pages share this same lazy view.
