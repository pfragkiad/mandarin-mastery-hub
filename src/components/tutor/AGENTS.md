- The Settings handwriting try pad (大) reads the live Trace/Recall strictness and Practice mode options, so it always judges strokes exactly as Practice will; its mode switch is local and never saved.
- FlashcardSessionProvider (root) keeps flashcard rounds across Details; Details/missed links set one detailTrail step so Back resumes the game.
- Shell side-menu docking per window size comes only from src/lib/nav-layout.ts (large docked, medium pin/hide remembered, small drawer), so markup/CSS never encode their own breakpoint rules.
- The five games (names, icons, destinations) come only from game-catalog.tsx, shared by the sidebar and the Start page, so the two never drift.
- The Sound chart keeps syllable and tone in the URL (s, t); its card Back uses soundTrail (createTrail in detail-trail.ts) keyed by history entry, so revisiting the same URL is never mistaken for a return.
- Sound chart "In a character" lists come only from exact catalogue readings via src/lib/syllable-characters.ts, so no reading is inferred from shape or words; radical characters link to their radical card only through an exact card glyph or a unique sourced Kangxi identity (variant key only when one form matches); those rows use the radical family's own rank and list before ordinary characters.
- DraftFilterForm `live` applies every edit synchronously (no wait cursor/frame delay) for result sets that opt in, so the applied URL catches up before the next keystroke; the Sound chart and libraries use explicit Apply.
- Sound chart dropdowns narrow through chartFilterOptions (applied search plus the other dropdown, never themselves, current value kept), so every offered initial/final still leads to syllables.
- On small screens (≤850px) the Sound chart card opens in PinyinSoundSheet, a top-anchored modal sharing .detail-sheet styles, so tone changes only grow the card downward; Previous/Next walk the visible grid and start a fresh soundTrail.
- On phones, DraftFilterForm `searchKey` adds a search-box X that clears only that text field (re-applying the other applied filters/modes, or just emptying unapplied typing), because phones hide the desktop clear-all X.
- DraftFilterForm `searchModeKey` (Pinyin/Exact) is ignored when deciding whether to offer Apply while the search text is empty, because a mode alone filters nothing; the toggled mode stays drafted and applies with the next text.
- Practice writing square size is a saved preference (practiceCanvasSize) set via a drag handle; the writer rebuilds only on release, so dragging never resets per frame and Reset preferences restores the default; a drag pauses Play, silences audio and fades the drawing via a DOM class (no rerender).
- Radical variant cards show conventional Chinese component names only from the audit's componentNaming.chineseName (or a reviewed contextual identity's componentName) with their recorded translation, never synthesized from English labels, so a null name stays absent.
- Simplified/traditional script groups come only from the owner-curated versioned file public/data/character-variants-v1.4.0.json (never the older generated character-variants.json); grouping is presentation only and happens within one library (Characters or Components, each only with its own records), so each form keeps its own record, rank and strokes.
- A v1.4.0 simplified key with any context_dependent_not_error note never shares a card: character-variants.ts moves its whole set into `related`, shown by RelatedWrittenForms with the recorded notes verbatim, and "Simplified · also traditional" appears only when a note documents the key unchanged (unchangedSense or an "A → A" example), so partial correspondences are never presented as equivalents.
- Readings joined with " / " render through reading-speakers.tsx (MultiReadingSpeakers), one speaker per exact reading, because the joined string matches no recording.
- Practice shows ScriptForms tiles (destination practice, Components records when opened from Components or component-only) in place of the single glyph for script-grouped characters when Include traditional is on, so each form is practised as its own record.
