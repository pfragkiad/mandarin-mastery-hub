# HSK word audio sources

Importer-only, checksum-bound metadata for matching Level 2–5 headwords **and their exact recorded readings** to the same Yue Tan / Shtooka collection used by Level 1. No sentence recordings or assembled syllable audio are provided.

The metadata index is pinned to SHA-256 `59052c11fcdfd0f0f21fcaf9618371f269f4a0228eaed920c3923e827f8d81a6`. Audio comes from [audio-cmn commit f759a0f18f27690742957619e1248ed91e9b3f2c](https://github.com/hugolpz/audio-cmn/tree/f759a0f18f27690742957619e1248ed91e9b3f2c), `64k/hsk`. Every downloaded MP3 must match that commit's Git blob and byte count before its SHA-256 is recorded. Normal caches and upload pointers remain external inputs. The owner-requested temporary `recordings/` MP3 handoff has been uploaded to the Lovable CDN, verified and removed; runtime attachments are CDN URLs only. A future re-import downloads into an external `--cache` with `--prepare` (or `--stage` for another owner-approved handoff).

From the repository root (PowerShell examples):

```powershell
python scripts/import-hsk-level2-audio.py --prepare --cache "$env:TEMP/mandarin-hsk2-audio"
python scripts/import-hsk-level2-audio.py --stage --cache "$env:TEMP/mandarin-hsk2-audio"
python scripts/import-hsk-level2-audio.py
# Requires the project's authenticated lovable-assets executable.
python scripts/import-hsk-level2-audio.py --upload --cache "$env:TEMP/mandarin-hsk2-audio" --uploads "$env:TEMP/mandarin-hsk2-audio-uploads"
python scripts/import-hsk-level2-audio.py --uploads "$env:TEMP/mandarin-hsk2-audio-uploads" --write --report reports/hsk-level2-audio.json
python scripts/import-hsk-level2-audio.test.py
# Levels 3 and 4 (--level N): extract hsk-level-N-audio.zip outside the repository first.
python scripts/import-hsk-word-audio.py --level 4 --cache <extracted>/recordings --verify-cache
python scripts/import-hsk-word-audio.py --level 4 --cache <extracted>/recordings --upload --uploads <uploads-dir>
python scripts/import-hsk-word-audio.py --level 4 --uploads importer/data/hsk-audio/level4-uploads.json --write --report reports/hsk-level4-audio.json
python scripts/import-hsk-word-audio.test.py
```

Only verified Lovable CDN pointers for this project, media type and byte count can become new attachments. A trusted existing word recording may also be reused for the exact headword/reading. Partial imports attach only available recordings and report every pending upload; they never invent URLs. Missing, ambiguous or differently toned source readings stay unattached. Existing attachments are not overwritten; reimports preserve timestamps. Text, source identities, examples, categories and other levels remain untouched.

All 166 eligible entries are attached; 13 different recorded readings and 21 missing headwords stay unattached. The two 花 entries share the same exact recording; the two 过 entries do not, because `guo` and `guò` are different readings. [The coverage report](../../../reports/hsk-level2-audio.md) records the upload state and exceptions. Level 4: all 797 exact matches are attached; 36 different recorded readings and 167 missing headwords stay unattached — see [the Level 4 report](../../../reports/hsk-level4-audio.md). ## Level 5 CDN-upload package

**Status: completed.** The package was verified, uploaded and attached; pointers are in `level5-uploads.json` and results in [the Level 5 report](../../../reports/hsk-level5-audio.md). [Package coverage and exclusions](../../../reports/hsk-level5-audio-package.json) include its SHA-256 and byte count. This step does not attach audio or invent CDN URLs. The ZIP includes checksum-named MP3s, the exact manifest/source handoff, original index/notice and upload instructions. MP3s and the ZIP must remain outside the repository.

```powershell
python scripts/prepare-hsk-word-audio.py --level 5 --cache "$env:TEMP/mandarin-hsk5-audio/recordings" --output "$env:TEMP/mandarin-hsk5-audio/hsk-level-5-audio.zip" --report reports/hsk-level5-audio-package.json
# After extracting the ZIP outside the repository:
python scripts/import-hsk-word-audio.py --level 5 --cache <extracted>/recordings --verify-cache
# In the authenticated CDN upload environment:
python scripts/import-hsk-word-audio.py --level 5 --cache <extracted>/recordings --upload --uploads <external-uploads-dir>
python scripts/import-hsk-word-audio.py --level 5 --uploads <external-uploads-dir> --write --report reports/hsk-level5-audio.json
```

Returned CDN pointers are stored durably as `level5-uploads.json`; reattach with `--uploads importer/data/hsk-audio/level5-uploads.json --write`. The importer can attach only verified upload pointers or exact previously attached recordings from the same source; sentence drafts, other fields and earlier levels remain unchanged.

The Level 5 v1.0.1 vocabulary update changes meanings and examples, without changing any audio headword/reading identity. The loader verifies the current source against the manifest’s checksum-bound `compatibleHandoffs` and compares every identity again; MP3 checksums and original source attribution remain unchanged. Future rewritten sentences do not inherit word recordings.
