# Translation source batches

`001.json`–`099.json` are deterministic subsets of the pinned original Shuowen
archive, ordered by numeric source ID: 100 records per batch, 33 in the last.
Generate with `python scripts/shuowen-translation-batches.py --prepare` from the
repository root. No translation is generated by this command.

Translation authors, the `save_batch` helper and `scripts/import-etymology.py`
consume these files. Each record preserves original ID, headword and Chinese
explanation, with its exact UTF-8 text SHA-256. Root metadata retains upstream
revision, archive hash and full original license notice. English batch metadata
also binds to the exact source-batch bytes; keep LF and do not edit these files
manually. See the [translation guide](../README.md) and
[schema](../translation.schema.json).
