# Conversational Mandarin — source material

Editorial inputs behind the 15 Conversational Mandarin lessons in
[src/data/study_lessons/lessons/conversational/](../../../../src/data/study_lessons/lessons/conversational/README.md).
They are kept unmodified for traceability and audit; the app never imports them.

| File | Purpose |
| --- | --- |
| `source_transcripts/` | The 16 user-provided audio transcripts (CD1 Lesson 1 – CD8 Lesson 16), unmodified. Lesson reports cite their track/time/line anchors. |
| `EXTRACTION_REVIEW_INDEX.json` | All 880 extracted vocabulary/expression rows with their review status (curated, transcript-attested, drill fragment, excluded). Only curated rows appear in lessons. |

Consumers: none at runtime; read by editors when reviewing or regenerating the lessons.
